# Project Management CLI

This repository includes a Python-based command-line tool for managing users, projects, and tasks.

## Overview

- Add and list users
- Create and manage projects
- Add tasks and track completion
- Persist data in JSON files

## Quick start

```bash
python main.py --help
```

For full usage details, see the project README in the repository root.
